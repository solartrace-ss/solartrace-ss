# ☀️ SolarTrace - Smart Solar Cooking for South Sudan

**UbuntuNet Alliance Women Hackathon 2026 | Phase I - Week 1**

## Project Overview
SolarTrace is a smart IoT-connected solar cooker with automatic sun tracking for rural communities in South Sudan.

## The Problem
- 7% electricity access rate
- >80% households depend on biomass
- 4-6 hours daily fuel collection
- ~20% forest cover loss since 2000

## Our Solution
- RTC-based automatic sun tracking (10-minute intervals)
- Blynk IoT platform integration
- Four cooking modes (cooking, sterilization, boiling, warming)
- Safety mechanism (130°C shutdown)
- SD card data logging
